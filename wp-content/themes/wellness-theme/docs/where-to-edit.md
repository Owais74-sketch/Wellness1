# Where to Edit — Wellness Theme Content Guide

> **For the site owner.** Everything visible on the site can be changed without touching code.
> Go to **WordPress Admin → Appearance → Customize** for most text, or open the page/post in the editor for body content.

## Page Editor — WordPress Admin → Pages

Each page's **body content** (paragraphs, headings, lists) is edited directly in the WordPress block editor.

| Page | URL | Edit at |
|---|---|---|
| Home | `/` | Pages → Home (or use Customizer for section text) |
| About | `/about/` | Pages → About |
| Contact | `/contact/` | Pages → Contact |
| Privacy Policy | `/privacy-policy/` | Pages → Privacy Policy |
| Terms | `/terms-of-service/` | Pages → Terms of Service |
| Medical Disclaimer | `/medical-disclaimer/` | Pages → Medical Disclaimer |
| Myths vs Facts | `/myths-vs-facts/` | Pages → Myths vs Facts |

### Page Extras meta box (shown below the editor)

Visible on every Page edit screen. Fields:

| Field | Purpose |
|---|---|
| Label (badge above title) | Small eyebrow badge (e.g. "About us"). Leave empty to hide. |
| Subtitle / Meta line | Introductory line under the title. Leave empty to hide. |
| Closing line | Sign-off sentence at the bottom of the content. Leave empty to hide. |
| Last updated text | Custom "Last reviewed" note (e.g. "Last reviewed: January 2026"). Leave empty to use the automatic modified date. |

## Theme Options — Appearance → Customize → Wellness Theme Options

Colours, fonts, Quick Exit URL, and default dark/light mode are set here. Do not change these unless you are rebranding the site.

## Demo-Specific Settings (Portfolio Demo)

| Setting | Location |
|---|---|
| Show/hide yellow demo notice bar | Customizer → Top Bar → "Show demo notice bar" |
| Demo notice bar text | Customizer → Top Bar → "Demo Notice Bar Text" |
| Show/hide Quick Exit button | Customizer → Top Bar → "Show Quick Exit button" (default OFF) |
| Consultation types | WP Admin → Consultations → Consultation Types |
| Demo consultants | WP Admin → Users (role: Wellness Consultant) |
| Consultant availability | WP Admin → Consultations → Availability |
| Email templates | WP Admin → Consultations → Email Templates |
| Payment test mode | WP Admin → Consultations → Payments → Test Mode |

### Turn features ON/OFF

```
WP Admin → Consultations → Settings:
  - Consultations Enabled: controls booking pages visibility
  - Anonymous Questions Enabled: controls Ask a Question page
```
